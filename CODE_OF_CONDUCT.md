# Code of Conduct

Be respectful, constructive, and considerate in issues, pull requests, reviews,
and other project spaces. Welcome contributors regardless of background,
experience, identity, or disability. Critique the work, not the person.

Harassment, threats, discrimination, sexualized content, personal attacks,
impersonation, and publishing another person's private information are not
acceptable. Do not pressure contributors to disclose personal or account data.

Maintainers may edit or remove inappropriate content, lock discussions, or limit
participation using GitHub's moderation tools. Decisions should be proportionate
to the behavior and applied consistently. Constructive disagreement and good-faith
technical criticism are welcome.

Report abuse privately using
[GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Do not publish sensitive conduct reports in an issue. For software vulnerabilities,
use the private channel described in [SECURITY.md](SECURITY.md).
